# DATALab — Site institucional

Projeto web estático para o DATALab — Data, Analytics, Technologies & Artificial Intelligence, IFPB Campus Soledade.

## Arquivos
- `index.html` — estrutura e conteúdo da página
- `styles.css` — identidade visual e responsividade
- `script.js` — menu mobile e ano automático no rodapé

## Como visualizar
Abra o arquivo `index.html` diretamente no navegador.

Para desenvolvimento local, também é possível usar qualquer servidor HTTP simples, por exemplo:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.
